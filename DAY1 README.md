Data Analytics – Task List

  -What is Data?
  Raw facts and information used for analysis.

  -What is Data Analytics?
  Process of analyzing data to find useful insights.

 -Data Analyst Role
  Collects, cleans, analyzes, and visualizes data.

 -Analyst vs Scientist vs Engineer
  Analyst finds insights, Scientist builds predictions, Engineer manages data systems.

- Types of Data
  Qualitative, Quantitative, Structured, Semi-structured, Unstructured.

- Structured vs Unstructured
  Structured has a fixed format; unstructured has no fixed format.

- Qualitative vs Quantitative
  Qualitative describes; quantitative uses numbers.

- Data Sources
  Databases, Excel, CSV, APIs, websites, and surveys.

- Analyst Workflow
  Collect → Clean → Analyze → Visualize → Insights → Decision.
