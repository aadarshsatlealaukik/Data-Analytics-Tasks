Day 10 tasks summary 

Population: The entire group of people or items you want to study.

Sample: A smaller group selected from a population for analysis.

Variables: Characteristics or values that can change between observations.

Mean: The average of all values, calculated by dividing their sum by the number of values.

Median: The middle value when data is arranged in order.

Mode: The value that occurs most frequently in a dataset.

Range: The difference between the maximum and minimum values.

Variance: A measure of how spread out values are from the mean using squared differences.

Standard Deviation: Measures how much values typically vary from the mean.

Percentiles: Values that divide ordered data according to specified percentage cutoffs.

Quartiles: Three cutoff values (Q1, Q2, Q3) that divide ordered data into four sections.
