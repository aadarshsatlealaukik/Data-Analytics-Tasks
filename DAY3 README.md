Files: Data stored in file formats such as CSV, Excel, or JSON.
Excel: A spreadsheet tool used to store and analyze data.
CSV: A simple text-based format where values are separated by commas.
Database: A system used to store and manage structured data.
Data Warehouse: Centralized storage optimized for business analysis and reporting.
Data Lake: Storage for large amounts of raw data in various formats.
ETL: Extract, Transform, and Load.
ELT: Extract, Load, and Transform.
API: A method that allows applications to communicate and exchange data.
JSON: A lightweight format used to represent and exchange structured data.
Data Pipeline: An automated process that moves and processes data between systems.
Data Quality: The degree to which data is accurate, complete, consistent, valid, unique, and timely.
