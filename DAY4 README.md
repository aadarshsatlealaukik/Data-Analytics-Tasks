DAY4 Tasks summary


Workbook - Complete Excel file containing multiple sheets.
Worksheet -	Individual sheet/page inside a workbook.
Rows -	Horizontal records identified by numbers.
Columns -	Vertical fields identified by letters.
Cells	- Individual boxes formed by a row and column.
Data Types -	Different kinds of data such as text, numbers, dates, and percentages.
Tables -	Structured data ranges that make sorting, filtering, and formulas easier.
Formatting -	Changing the appearance and number display of data.
Sorting -	Arranging data in a specific order, such as A–Z or highest–lowest.
Filtering -	Showing only the data that matches selected conditions.
Freeze Panes -	Keeps selected rows or columns visible while scrolling.
Basic Calculations -	Performing operations like SUM, AVERAGE, MAX, MIN, multiplication, and division.
Relative Reference - A cell reference that changes when a formula is copied.
Absolute Reference -	A cell reference like $A$1 that stays fixed when a formula is copied
