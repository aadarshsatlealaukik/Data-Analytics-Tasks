The system uses Pandas and NumPy to clean student data, calculate marks and percentages, identify toppers, analyze subject performance, and export reports into Excel files.

## Business Objectives

- Organize student academic records.
- Calculate total marks and percentages.
- Evaluate student pass/fail status.
- Identify class toppers.
- Analyze subject-wise performance.
- Generate class-wise and overall reports.
- Reduce manual work in academic reporting.

## Tools & Technologies

- Python
- Pandas
- NumPy
- CSV
- Microsoft Excel

## Project Features

- Read student records from a CSV file.
- Clean column names.
- Convert subject marks into numeric values.
- Calculate total marks.
- Calculate percentage out of 500.
- Display class-wise student records.
- Identify class toppers.
- Calculate subject-wise averages.
- Classify students as pass or fail.
- Export class-wise reports.
- Generate an overall analysis report.

## Key Findings

The system supports analysis of:

- Class-wise academic performance.
- Highest-scoring students in each class.
- Average marks in individual subjects.
- Overall student percentages.
- Number of students passing and failing.
- Differences in performance across classes.

## Methodology
