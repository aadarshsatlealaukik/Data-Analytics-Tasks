Day5 Task's Summary

- SUM: Adds multiple numbers together.
  =SUM(A2:A10)
- AVERAGE: Calculates the average of numbers.
  =AVERAGE(A2:A10)
- MIN/MAX: Finds the smallest and largest value.
  =MIN(A2:A10)/ =MAX(A2:A10)
- COUNT: Counts cells containing numbers.
  =COUNT(A2:A10)
- COUNTA: Counts all non-empty cells.
  =COUNTA(A2:A10)
- IF: Returns one result if a condition is true and another if false.
  =IF(B2>=50, "P","F")
- AND: Returns TRUE when all given conditions are true.
  =AND(B2>=50, C2="Yes")
- OR: Returns TRUE when at least one condition is true.
  =OR(B2="D',"B2"="I")
- Nested IF: Uses multiple IF conditions to handle different situations.
  =IF(B2>=B0,"A+",IF(B2>=60"A","Need Improvment"))
- IFERROR: Shows an alternative result when a formula produces an error.
  =IFERROR(A2/B2,0)
