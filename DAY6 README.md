## Day 6: Conditional Functions & Business-Based Formula Problems

### 1. SUMIF Function

**Definition:** The SUMIF function adds numerical values that meet a single specified condition.

**Syntax:**
`=SUMIF(range, criteria, [sum_range])`

**Parameters:**
- `range`: The cells Excel checks against the condition.
- `criteria`: The condition that must be satisfied.
- `sum_range`: The cells containing the values to add. This argument is optional.

**Example:**

`=SUMIF(B2:B10,"Laptop",C2:C10)`

**Explanation:** Checks cells B2:B10 for the product name `Laptop` and adds the corresponding values from C2:C10.

**Business application:** Calculate total revenue generated by a specific product.

**Another example:**

`=SUMIF(A2:A100,"Won",B2:B100)`

This adds the values in column B for records whose status in column A is `Won`.

### 2. SUMIFS Function

**Definition:** The SUMIFS function adds numerical values that satisfy multiple specified conditions simultaneously.

**Syntax:**
`=SUMIFS(sum_range, criteria_range1, criteria1, [criteria_range2, criteria2], ...)`

**Parameters:**
- `sum_range`: The values to add.
- `criteria_range1`: The range for the first condition.
- `criteria1`: The first condition.
- Additional criteria range and criteria pairs: Optional extra conditions.

**Example:**

`=SUMIFS(D2:D100,B2:B100,"Laptop",C2:C100,"Indore")`

**Explanation:** Adds values from D2:D100 only when the product in column B is `Laptop` and the city in column C is `Indore`.

**Business application:** Calculate total laptop revenue generated in Indore.

**Another example:**

`=SUMIFS(I2:I51,F2:F51,"Won",B2:B51,"Feb-2026")`

This adds the values in column I when the deal status is `Won` and the month field in column B contains `Feb-2026`.

*Note: The month criterion must match the actual data format. If column B contains real Excel dates, use date boundaries instead of a text month label.*

### 3. COUNTIF Function

**Definition:** The COUNTIF function counts the number of cells in a range that satisfy a single condition.

**Syntax:**
`=COUNTIF(range, criteria)`

**Parameters:**
- `range`: The cells to evaluate.
- `criteria`: The condition that determines which cells to count.

**Example:**

`=COUNTIF(B2:B100,"Indore")`

**Explanation:** Counts how many cells in B2:B100 contain `Indore`.

**Business application:** Count the number of customers, orders, or employees associated with a particular category.

**Another example:**

`=COUNTIF(C2:C100,">=10000")`

This counts the cells in C2:C100 containing numerical values greater than or equal to 10,000.

### 4. COUNTIFS Function

**Definition:** The COUNTIFS function counts records that satisfy multiple conditions simultaneously.

**Syntax:**
`=COUNTIFS(criteria_range1, criteria1, [criteria_range2, criteria2], ...)`

**Parameters:**
- `criteria_range1`: The range for the first condition.
- `criteria1`: The first condition.
- Additional criteria range and criteria pairs: Optional extra conditions.

**Example:**

`=COUNTIFS(B2:B100,"Indore",C2:C100,"Won")`

**Explanation:** Counts records where the city is `Indore` and the deal status is `Won`.

**Business application:** Count successful sales deals in a particular region or orders belonging to a specific category and status.

**Another example:**

`=COUNTIFS(A2:A100,">=1000",A2:A100,"<=5000")`

This counts numerical values in A2:A100 that are between 1,000 and 5,000, including both endpoints.

### 5. AVERAGEIF Function

**Definition:** The AVERAGEIF function calculates the arithmetic average of values that satisfy a single condition.

**Syntax:**
`=AVERAGEIF(range, criteria, [average_range])`

**Parameters:**
- `range`: The cells checked against the condition.
- `criteria`: The condition to satisfy.
- `average_range`: The numerical values to average. If omitted, Excel averages the cells in `range`.

**Example:**

`=AVERAGEIF(B2:B100,"Laptop",C2:C100)`

**Explanation:** Calculates the average of the values in C2:C100 for records where B2:B100 contains `Laptop`.

**Business application:** Calculate the average revenue generated by a specific product.

**Another example:**

`=AVERAGEIF(A2:A100,"Indore",B2:B100)`

This calculates the average of the values in column B for records associated with Indore in column A.

### 6. AVERAGEIFS Function

**Definition:** The AVERAGEIFS function calculates the arithmetic average of values that satisfy multiple conditions simultaneously.

**Syntax:**
`=AVERAGEIFS(average_range, criteria_range1, criteria1, [criteria_range2, criteria2], ...)`

**Parameters:**
- `average_range`: The numerical values to average.
- `criteria_range1`: The range for the first condition.
- `criteria1`: The first condition.
- Additional criteria range and criteria pairs: Optional extra conditions.

**Example:**

`=AVERAGEIFS(D2:D100,B2:B100,"Laptop",C2:C100,"Indore")`

**Explanation:** Calculates the average of values in D2:D100 only for records where the product is `Laptop` and the city is `Indore`.

**Business application:** Calculate average revenue for a particular product in a particular region.

**Another example:**

`=AVERAGEIFS(D2:D100,B2:B100,"Won",C2:C100,">=5000")`

This calculates the average of D2:D100 for records with a `Won` status in column B and a value of at least 5,000 in column C.

### 7. Logical Conditions in Excel

**Definition:** Logical conditions are expressions that evaluate whether a specified requirement is satisfied. They commonly produce TRUE or FALSE results and can be used to filter, count, sum, average, or classify data.

**Common logical operators:**

- `=` means equal to.
- `<>` means not equal to.
- `>` means greater than.
- `<` means less than.
- `>=` means greater than or equal to.
- `<=` means less than or equal to.

**Examples:**

**Equal to:**

`=COUNTIF(A2:A100,"Won")`

Counts cells containing `Won`.

**Not equal to:**

`=COUNTIF(A2:A100,"<>Won")`

Counts non-empty cells that do not contain `Won`. To count all cells other than `Won`, including blanks, use a separate approach because this criterion generally excludes blank cells.

**Greater than:**

`=SUMIF(B2:B100,">5000",C2:C100)`

Adds the values in column C where the corresponding values in column B exceed 5,000.

**Between two values:**

`=COUNTIFS(B2:B100,">=1000",B2:B100,"<=5000")`

Counts values between 1,000 and 5,000, including the boundaries.

**Combining conditions:**

`=IF(AND(B2>=50000,C2="Yes"),"Eligible","Not Eligible")`

Returns `Eligible` only if B2 is at least 50,000 and C2 contains `Yes`.

### 8. Business-Based Formula Problems

Business-based formula problems involve applying Excel functions to answer practical questions using real business data.

A Data Analyst uses these formulas to measure performance, investigate trends, and support business decisions.

**Problem 1: Calculate Total Sales for a Product**

Business question: What is the total revenue generated by laptops?

Formula:

`=SUMIF(B2:B100,"Laptop",D2:D100)`

Explanation: Adds revenue from column D for all records where column B contains `Laptop`.

**Problem 2: Calculate Sales for a Product in a Region**

Business question: What is the total laptop revenue in Indore?

Formula:

`=SUMIFS(D2:D100,B2:B100,"Laptop",C2:C100,"Indore")`

Explanation: Adds revenue only when both conditions are satisfied.

**Problem 3: Count Successful Sales Deals**

Business question: How many deals have been marked as Won?

Formula:

`=COUNTIF(F2:F100,"Won")`

Explanation: Counts the records with a `Won` status in column F.

**Problem 4: Count Won Deals in a Specific Region**

Business question: How many deals were won in Indore?

Formula:

`=COUNTIFS(C2:C100,"Indore",F2:F100,"Won")`

Explanation: Counts records where the region is Indore and the status is Won.

**Problem 5: Calculate Average Revenue for a Product**

Business question: What is the average revenue per laptop record?

Formula:

`=AVERAGEIF(B2:B100,"Laptop",D2:D100)`

Explanation: Averages the revenue values associated with laptop records.

**Problem 6: Calculate Average Revenue for Won Deals in Indore**

Business question: What is the average revenue of successful deals in Indore?

Formula:

`=AVERAGEIFS(D2:D100,C2:C100,"Indore",F2:F100,"Won")`

Explanation: Averages revenue only for records where the region is Indore and the deal status is Won.

### 9. SUMIF vs. SUMIFS, COUNTIF vs. COUNTIFS, and AVERAGEIF vs. AVERAGEIFS

**SUMIF vs. SUMIFS**
- SUMIF adds values using one condition.
- SUMIFS adds values using multiple conditions.
- SUMIF places the criteria range and condition before the optional sum range.
- SUMIFS places the sum range first, followed by criteria range and condition pairs.

**COUNTIF vs. COUNTIFS**
- COUNTIF counts cells meeting one condition.
- COUNTIFS counts records meeting multiple conditions.

**AVERAGEIF vs. AVERAGEIFS**
- AVERAGEIF calculates an average using one condition.
- AVERAGEIFS calculates an average using multiple conditions.

**Important rule:** In SUMIFS, COUNTIFS, and AVERAGEIFS, all conditions must be satisfied for a record to qualify. The criteria ranges should also have compatible dimensions.

### 10. Day 6 Key Takeaways

- **SUMIF:** Adds values based on one condition.
- **SUMIFS:** Adds values based on multiple conditions.
- **COUNTIF:** Counts cells meeting one condition.
- **COUNTIFS:** Counts records meeting multiple conditions.
- **AVERAGEIF:** Calculates an average based on one condition.
- **AVERAGEIFS:** Calculates an average based on multiple conditions.
- **Logical Conditions:** Define requirements using operators such as `=`, `>`, `<`, and `>=`.
- **Business-Based Formula Problems:** Apply formulas to calculate sales, count customers or deals, and analyze average revenue.

**Day 6 Learning Objective:** Learn to apply conditional Excel functions to business datasets, calculate meaningful performance measures, and answer business questions accurately using one or multiple criteria.
