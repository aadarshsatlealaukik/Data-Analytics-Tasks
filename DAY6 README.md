Day 6 Tasks Summary:-

- SUMIF: Adds values based on one condition.
- SUMIFS: Adds values based on multiple conditions.
- COUNTIF: Counts cells that meet one condition.
- COUNTIFS: Counts cells/rows that meet multiple conditions.
- AVERAGEIF: Calculates the average based on one condition.
- AVERAGEIFS: Calculates the average based on multiple conditions.
- Logical Conditions: Used to check conditions and return results based on TRUE/FALSE.
- Business-Based Formula Problems: Use formulas to answer real business questions like total sales, customer count, or average revenue.
