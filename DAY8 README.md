Day 8 Tasks 

- Pivot Tables: Summarize and analyze large datasets by categories using drag-and-drop fields.
   Syntax: Insert → PivotTable → Rows + Columns + Values + Filters
- Grouping: Combine dates/numbers into meaningful groups like Months, Quarters, Years, or ranges.
  Syntax: Right-click field → Group → Select By
- Calculated Fields: Create a new metric inside a Pivot Table using existing fields.
  Syntax: =Field1 * Field2 or =Field1 / Field2
- Filters: Show only the data that matches specific conditions.
  Syntax: Field → Filter → Select criteria
- Slicers: Interactive buttons that let users quickly filter Pivot Tables visually.
  Syntax: PivotTable Analyze → Insert Slicer → Select Field
- Pivot Charts: Convert Pivot Table results into charts for visual analysis.
  Syntax: PivotTable Analyze → PivotChart → Select Chart Type
- Business Reporting: Present KPIs, trends, comparisons, and insights in a clear format for business decisions.
  Syntax: Data → Analysis → KPI → Chart → Insight → Recommendation
