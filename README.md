Dashboard Principles: Guidelines for designing clear, simple, and useful dashboards that communicate insights quickly.

KPI Cards: Visual cards that display important business metrics such as total sales, profit, and revenue.

Charts: Visual representations of data used to identify trends, patterns, and comparisons.

Interactive Reports: Reports that let users explore data using filters, slicers, and drill-downs.

Power Query: A data preparation tool used to import, clean, and transform data before analysis.

Importing Data: Bringing data into a tool like Power BI from Excel, SQL databases, CSV files, or other sources.

Cleaning Data: Fixing missing values, duplicates, errors, and inconsistent formats to improve data quality.

Transformations: Changing data structure, format, or values to make it suitable for analysis.

Refresh Concept: Updating a report with the latest data from its connected source.
